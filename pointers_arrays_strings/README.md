# C - Pointers, Arrays and Strings

This project introduces pointers, arrays, strings and memory manipulation in C.

## Learning objectives

- Understand pointers and how to use them.
- Understand arrays and how to access their elements.
- Understand the differences between pointers and arrays.
- Manipulate strings using pointers and array indexing.
- Understand variable scope.

## Tasks

| File | Description |
|---|---|
| 0-reset_to_98.c | Update an integer through a pointer |
| 1-swap.c | Swap two integer values |
| 2-strlen.c | Calculate string length |
| 3-puts.c | Print a string |
| 4-print_rev.c | Print a string in reverse |
| 5-rev_string.c | Reverse a string in place |
| 6-puts2.c | Print every other character |
| 7-puts_half.c | Print the second half of a string |
| 8-print_array.c | Print an integer array |
| 9-strcpy.c | Copy a string |
| 100-atoi.c | Convert a string to an integer |

## Compilation

All source files are intended to compile with:

gcc -Wall -Werror -Wextra -pedantic -std=gnu89

## Header

All function prototypes are declared in `main.h`.

The `_putchar` implementation is supplied by the Holberton testing environment.
