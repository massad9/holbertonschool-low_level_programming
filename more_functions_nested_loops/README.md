# C - More functions, more nested loops

This project focuses on functions, nested loops, function prototypes,
header files, and variable scope in C.

## Task 0: isupper

The function `_isupper(int c)` checks whether a character is uppercase.

- Returns 1 if the character is between 'A' and 'Z'.
- Returns 0 otherwise.

## Compilation

Files are compiled using:

gcc -Wall -Werror -Wextra -pedantic -std=gnu89
